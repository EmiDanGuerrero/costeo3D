# Costeo3d

Sistema de escritorio para gestionar costos, inventario, presupuestos y trabajos de impresión 3D.

Desarrollado en Java con JavaFX, MySQL y JDBC.

## Estado

Proyecto en proceso de desarrollo.

## Base de datos

Los scripts SQL se encuentran en la carpeta `database/`.

- `inicializacion.sql`: creación de la base de datos y tablas.
- `datos_prueba.sql`: datos y operaciones de prueba.
- `consultas.sql`: consultas SQL utilizadas por el sistema.

## Tecnologías

- Java
- JavaFX
- MySQL
- JDBC
